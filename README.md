# GAME1 - RPG Universidad

Un juego de rol desarrollado en C con Raylib, ambientado en una universidad donde 6 estudiantes únicos se enfrentan a sus profesores en combate académico.

## Características

- **6 Personajes Jugables**: Robert, Franco, Coutencos, Fercha, Aldo y Chema
- **Sistema de Combate**: Combate por turnos contra profesores enemigos
- **Profesores Enemigos**: 5 tipos diferentes de profesores con IA
- **Sistema de Experiencia**: Sube de nivel derrotando enemigos
- **Mapa Universitario**: Explora aulas y pasillos de la universidad

## Compilación

```bash
make
```

## Ejecución

```bash
./rpg
```

## Controles

- WASD: Movimiento
- ESPACIO: Atacar en combate
- ESC: Huir del combate
- R: Reiniciar (en Game Over/Victoria)

Consulta `GAME_GUIDE.md` para información detallada sobre personajes y mecánicas.
